# Week 2 - Data Collection, Cleaning & Preprocessing
## Project
Reducing Delivery Delays in E-Commerce Logistics
## Description
This week focuses on collecting, cleaning and preprocessing logistics delivery data.
The dataset contains delivery information such as delivery person details, weather conditions, road traffic density, distance, vehicle condition and delivery time.
## Work Completed
- Checked dataset structure and data types
- Identified and handled missing values
- Standardized time values
- Checked duplicate records
- Detected outliers using IQR
- Normalized numerical features using MinMaxScaler
- Verified the final cleaned dataset
- Saved the preprocessed dataset as `zomato_preprocessed.csv`
## Dataset
Dataset: Zomato Delivery Dataset

Records: 38,964  
Columns: 22
